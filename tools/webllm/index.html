WebLLM (local)

Run models entirely in your browser with WebGPU — zero API key, zero server, zero cost.

WebLLM — run models in the browser

WebLLM runs LLMs locally in your browser using WebGPU. No API key, no server, no privacy concerns — the model runs on your own hardware.

Requirements

  • A recent Chrome/Edge/Firefox with WebGPU enabled.
  • Enough RAM (8–16 GB depending on the model).
  • Patience for the first model download (hundreds of MB to a few GB).

Free models (examples)

  • Llama-3.2-1B-Instruct — small and fast.
  • Qwen2.5-0.5B-Instruct — tiny, runs almost anywhere.
  • Mistral-7B-Instruct — better quality, larger download.

Why use it

  • 100% free and private — nothing leaves your device.
  • Great fallback when you don’t want to share content with an API.
  • PromptForge’s Run page can be pointed at any OpenAI-compatible or keyless endpoint; WebLLM is the “fully local” option to understand, even though the in-page Run uses the keyless Pollinations endpoint by default for instant results.
