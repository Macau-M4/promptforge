About PromptForge

PromptForge is a public library of AI prompts, special commands, tools and workflows — plus the guides that teach you how to use them. It exists because most "prompt databases" are locked behind signups, newsletters, or paywalls. Ours isn't.

The promise: 100% free, forever

Every design decision follows one rule: zero recurring cost, zero credit card, zero paid service. Concretely:

  • Hosting — static site on GitHub Pages (or Cloudflare/Vercel/Netlify free tiers). No server bill.
  • Database — the git repo itself. Prompts are markdown files; votes are stored locally in your browser.
  • Auth — GitHub OAuth Device Flow. No paid auth provider.
  • LLM — free providers only: Pollinations (keyless), Google AI Studio, Groq, OpenRouter free models, or local WebLLM.
  • Payments — none. No Stripe, no subscription, no paywall, no ads.

How it works

The site is fully static. Content lives in /src/content/ as markdown with a Zod-validated schema. A GitHub Action validates every contribution and auto-tags new submissions. The Run feature calls free LLM APIs directly from your browser — your key (if any) never leaves your device.

Contribute

PromptForge is only as good as the community's prompts. Fork the repo, add a markdown file, and open a PR — CI does the rest. See the Contribute page for the full flow.
