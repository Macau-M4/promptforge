About PromptForge

PromptForge คือคลังสาธารณะของ AI prompts, คำสั่ง, tools และ workflows — พร้อมคู่มือสอนวิธีใช้งาน สาเหตุที่สร้างเพราะ "คลัง prompt" ส่วนใหญ่ล็อกหลังการสมัคร newsletter หรือ paywall — แต่ของเราไม่เป็นแบบนั้น

The promise: 100% free, forever

ทุกการตัดสินใจยึดกฎเดียว: ค่าบริการต่อเดือนเป็นศูนย์ ไม่ต้องใช้บัตรเครดิต ไม่มี paid service:

  • Hosting — static site on GitHub Pages (or Cloudflare/Vercel/Netlify free tiers). No server bill.
  • Database — the git repo itself. Prompts are markdown files; votes are stored locally in your browser.
  • Auth — GitHub OAuth Device Flow. No paid auth provider.
  • LLM — free providers only: Pollinations (keyless), Google AI Studio, Groq, OpenRouter free models, or local WebLLM.
  • Payments — none. No Stripe, no subscription, no paywall, no ads.

How it works

เว็บเป็น static ทั้งหมด เนื้อหาอยู่ใน /src/content/ เป็น markdown ที่ผ่าน Zod schema — GitHub Action ตรวจทุก contribution และ auto-tag ให้ ส่วน Run feature เรียก free LLM API จากเบราว์เซอร์โดยตรง (key อยู่แค่ในเครื่องของคุณ)
