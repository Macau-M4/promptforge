Contribute a prompt

PromptForge is a git repo as its own database. Submitting a prompt is just a pull request that adds one markdown file. A GitHub Action validates it against the Zod schema and auto-tags it — no forms, no accounts beyond GitHub.

The file format

Every prompt is a markdown file with YAML frontmatter. Copy this template, fill it in, and the first fenced code block becomes the copyable prompt: 

---
title: "My amazing prompt"
description: "One sentence describing what it does."
category: "writing"          # writing | coding | productivity | analysis | creative | learning | marketing | automation
tags: ["writing", "editing"]
difficulty: "beginner"       # beginner | intermediate | advanced
model: "any"
author: "your-github-handle"
created: "2025-04-01"
updated: "2025-04-01"
upvotes: 0
downvotes: 0
version: 1
---

What happens next

  • Validate — a GitHub Action checks your frontmatter against the Zod schema.
  • Auto-tag — an Action reads your title + body and suggests/assigns a category if yours is missing or off.
  • Review — a maintainer merges, and your prompt goes live on the next deploy.
