Contribute a prompt

ส่ง Prompt ของคุณผ่าน GitHub pull request — เพิ่มไฟล์ markdown หนึ่งไฟล์ แล้ว Action จะตรวจ schema และ auto-tag ให้อัตโนมัติ

Step 01

Fork the repo

กด fork บน GitHub หนึ่งครั้ง

Fork repository →
Step 02

Add a prompt file

สร้างไฟล์ markdown ใน src/content/prompts/

Open the editor →
Step 03

Open a pull request

CI ตรวจ schema และ auto-tag หมวดหมู่ให้

Create a PR →

The file format

Prompt ทุกตัวคือไฟล์ markdown ที่มี YAML frontmatter — ลอก template นี้ไปกรอก แล้ว code block แรกจะกลายเป็น prompt ที่ก๊อปปี้ได้: 

---
title: "My amazing prompt"
description: "One sentence describing what it does."
category: "writing"          # writing | coding | productivity | analysis | creative | learning | marketing | automation
tags: ["writing", "editing"]
difficulty: "beginner"       # beginner | intermediate | advanced
model: "any"
author: "your-github-handle"
created: "2025-04-01"
updated: "2025-04-01"
upvotes: 0
downvotes: 0
version: 1
---

## The prompt

```text
Your prompt here. Use {{variable}} placeholders for inputs.
```
