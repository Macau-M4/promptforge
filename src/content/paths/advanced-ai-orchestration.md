# Advanced AI Orchestration

The **Master** track is about treating AI as a team member you direct. You'll build
multi-step pipelines, generate code you actually ship, and run research with citations.

## The mindset shift

- **Decompose** — break a big job into steps, and give each step its own prompt.
- **Verify** — never trust output you haven't checked; the model's job is a strong draft.
- **Compose** — feed one prompt's output into the next to build pipelines.

## Your path

1. **Clean inherited code** — run *Refactor & Explain Code*, then read the RISKS section carefully.
2. **Lock in behavior** — generate tests with *Unit Test Generator* and confirm every assertion.
3. **Build real tools** — use *Python Script Scaffolder* to turn a manual task into a CLI, then harden it with a code review.
4. **Write campaigns** — draft a full *Email Sequence Writer* arc, then edit the voice.
5. **Synthesize research** — feed several sources into *Research Synthesizer* and trace every claim to its citation.
6. **Direct creative projects** — design a world with *Worldbuilding Architect*, then generate a consistent *Image Style-Transfer Prompt* series.
7. **Decide under uncertainty** — use *Decision Matrix Helper* to make the call and surface its biggest assumption.

## When you're done

You'll be able to run a whole project — code, content, research, and creative — by
composing these prompts into a pipeline. That's the difference between using AI and
**orchestrating** it.
