## The prompt

```text
Write landing page copy for the following offer.

Product: {{product}}
Audience: {{audience}}
Main benefit / outcome: {{benefit}}
Objection to overcome: {{objection}}

Output:
1. HEADLINE — 3 options (one benefit-led, one curiosity-led, one proof-led).
2. SUBHEADLINE — one line that expands the headline.
3. BENEFITS — 4-5 benefit bullets written as outcomes, not features.
4. SOCIAL PROOF — 2 placeholder testimonial angles.
5. CTA — primary button text + a low-risk secondary CTA.
6. RISK REVERSAL — one line that lowers the barrier (e.g. free tier, no card).

Write in the voice of {{voice}}. Keep it specific and concrete — no "unlock your potential" filler.
```

## When to use it

Use it to draft a page fast, then edit hard. The best output is a starting point, not the final copy.

## Pro tip

Run it once per audience segment — the same product needs different copy for a solo founder vs. an enterprise buyer.
